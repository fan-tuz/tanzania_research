# Diagnostics

Questa cartella è riservata a diagnostiche e validazione. Non salvare qui tabelle di regressione finali.

File principali:
- `validation_diagnostics.ipynb`: coverage, support cells, balance descrittivo e mappe rapide.
- `coverage_key_variables.csv`: creato dal notebook.
- `support_cells_by_wave.csv`: creato dal notebook.
- `baseline_balance_descriptive.csv`: creato dal notebook.

Convenzione:
- risultati regressioni: `output/regressions/...`
- dataset intermedi/finali: `output/...`
- dati grezzi/reference: `data/...`
- diagnostiche: `diagnostics/...`
